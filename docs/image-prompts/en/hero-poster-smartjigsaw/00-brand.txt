######## A) ภาพเดสก์ท็อป — สัดส่วนตอน Gen 21:9 แล้วครอปบน-ล่างเป็น 2400×840 (ให้จุดเด่นอยู่กึ่งกลางแนวตั้ง) ########
Bright, modern tech-brand banner illustration in a polished 3D render style (soft glossy clay-like materials, soft studio lighting, subtle white-to-light-blue gradient background, small decorative dotted patterns, floating soft cubes and thin glowing connection lines).
Layout (very important): ultra-wide banner, aspect ratio 21:9. The LEFT 48% of the frame is a calm, empty, light gradient area reserved for a big headline, subtitle and bullet text that will be added later in a design tool.
The scene sits on the RIGHT 52%, vertically centered, with some elements overlapping toward the middle.
Brand colors: blue #1369D5, navy #0B1E36, light blue #5C9BEA, orange #FF9F2E accents.
No text, no letters, no numbers, no logos, no watermark, no readable UI text (use abstract blocks and icons on screens).
Scene: four large glossy jigsaw puzzle pieces (blue, navy, light blue, orange) interlocking into one square, each piece carrying a simple glowing icon (chat bubble with rising chart, shopping cart with POS screen, friendly AI robot face, code brackets in a window), thin glowing connection lines and small floating cubes around them.

(Negative) text, letters, numbers, logo, watermark, dark gloomy background, cluttered left side, distorted hands, blurry
