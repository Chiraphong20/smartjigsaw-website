โฟลเดอร์พรอมต์สำหรับ Gen ภาพของเว็บ Smart Jigsaw (ธีม Digital Navy: กรมท่าเข้ม + ส้ม)
=================================================================================

วิธีใช้
1) เลือกภาษา: en/ (อังกฤษ — ผลดีที่สุดกับโปรแกรม Gen ส่วนใหญ่) หรือ th/ (ไทย — ใช้กับ Gemini ฯลฯ)
2) เปิดไฟล์ .txt ที่ต้องการ → คัดลอกบล็อก "PROMPT" ทั้งหมดไปวาง (แต่ละไฟล์ครบในตัว ไม่ต้องต่อกับไฟล์อื่น)
3) ถ้ามีช่อง Negative prompt ให้คัดลอกบล็อก NEGATIVE ไปวางด้วย
4) ตั้งสัดส่วนภาพตามที่ไฟล์บอก แล้วครอป/ย่อเป็น "ขนาดสุดท้าย" ก่อนอัปโหลด
5) อัปโหลดที่หลังบ้าน (admin.jigsawbase.com) ในหมวดที่ระบุในบรรทัด "ใช้ที่" — ระบบเตือนถ้าขนาด/สัดส่วนผิด และดูผลในช่องตัวอย่างก่อนกดบันทึกได้
