# 📁 วางรูปภาพที่นี่

## โครงสร้างโฟลเดอร์

```
public/
└── images/
    ├── hero-banner.jpg          ← รูป Banner หน้าแรก (1920×1080)
    ├── growstore.jpg            ← รูป Growstore Dashboard
    └── capabilities/
        ├── units.jpg            ← แบ่งหน่วยของสินค้าได้
        ├── analytics.jpg        ← Dashboard ที่เข้าใจง่าย
        ├── inventory.jpg        ← จัดการคลังครุภัณฑ์และวัสดุ
        └── logistics.jpg        ← ติดตามการจัดส่งทุกขั้นตอน
```

## วิธีใช้งานในโค้ด

เรียกรูปด้วย path แบบนี้ได้เลย:

```
/images/hero-banner.jpg
/images/growstore.jpg
/images/capabilities/units.jpg
```

## ขนาดรูปแนะนำ

| รูป | ขนาด |
|-----|------|
| hero-banner | 1920 × 1080 px |
| growstore | 1200 × 750 px |
| capabilities | 800 × 500 px |
