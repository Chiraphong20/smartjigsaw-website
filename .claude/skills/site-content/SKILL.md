# site-content

ก่อนเริ่ม อ่าน `CLAUDE.md` (กติกา) และ `DESIGN.md` (สี ตัวอักษร ส่วนประกอบ) แล้วทำตามนั้น

## แก้ข้อมูลบริษัท
แก้ที่ `BRAND` ใน `src/site.ts` ที่เดียว (ชื่อ บริษัท ที่อยู่ เลขภาษี เบอร์ อีเมล ไลน์ เวลาทำการ) ทุกหน้าที่อ้างจะเปลี่ยนตาม
ชื่อแบรนด์ยังอยู่ใน `index.html` (`<title>`, description) ด้วย — แก้ให้ตรงกัน

## เพิ่ม/แก้ สินค้า
เพิ่มอ็อบเจกต์ใน `PRODUCTS` (`src/site.ts`) ครบทุกฟิลด์: `slug` (อังกฤษ-ขีด ไม่ซ้ำ), `name`, `short` (ประโยคเดียว), `summary` (2 ประโยค), `icon` (จาก lucide-react), `color` (hex ที่ตัดกับตัวอักษรขาวได้), `features` (3–4 ข้อ), `modules` (4 อัน `{title,text}`), `forWho`
เมนู ฟุตเตอร์ รายการสินค้า และหน้ารายละเอียด สร้างจากข้อมูลนี้เอง ไม่ต้องแก้ไฟล์อื่น
ถ้าเพิ่มสินค้าตัวที่ 6 ขึ้นไป ตรวจ Hero (`src/components/Hero.tsx` ใช้ `PRODUCTS[0..3]`) ว่าอยากให้ขึ้นสไลด์ด้วยไหม

## เพิ่มบทความ
เพิ่มใน `ARTICLES` — `slug` ไม่ซ้ำ, `category` เป็นหนึ่งใน `'ERP' | 'POS' | 'HRM' | 'ข่าวสาร'`, `date` รูปแบบ `YYYY-MM-DD` (พ.ศ. ใส่เป็นปีพ.ศ. ตรงๆ เช่น `2569-10-10` เพราะ `thaiDate` ไม่แปลงปี), `excerpt` 1–2 ประโยค, `body` เป็นอาร์เรย์ย่อหน้า (ไม่ใส่ HTML)
หน้าแรกแสดงบทความ 4 ชิ้นแรกของอาร์เรย์ — วางชิ้นใหม่ไว้บนสุด
ถ้าจะเพิ่มหมวดใหม่ ต้องแก้ทั้งชนิด `Article['category']` ใน site.ts และ `CATS` ใน `src/pages/Knowledge.tsx`

## เพิ่มหลักสูตร / บริการ
`COURSES` (`id`, `title`, `level`, `hours`, `price`, `topics[]`) และ `SERVICES` (`title`, `text`) — หน้าอบรมและบริการแสดงเป็นกริดอัตโนมัติ

## เพิ่มหน้าใหม่
1. สร้างคอมโพเนนต์ใน `src/pages/` เริ่มด้วย `<PageHead title=... lead=... crumbs=[...] />` (นำเข้าจาก `./Products`) แล้วเนื้อหาในแต่ละ `<section className="section">` + `<div className="wrap">`
2. เพิ่ม `<Route>` ใน `src/App.tsx`
3. ถ้าต้องอยู่ในเมนู เพิ่มที่ `NAV` ใน `site.ts`; ถ้าต้องอยู่ในฟุตเตอร์ แก้ `src/components/Layout.tsx`
4. ใช้คลาสที่มีอยู่ (`grid c2/c3/c4`, `card`, `tag`, `band`, `prose`, `btn primary/accent/ghost`, `form`) ก่อนเขียน CSS ใหม่ — ถ้าจำเป็นต้องเพิ่ม CSS ให้ใช้ตัวแปรที่ `:root`

## เขียนข้อความ
- ภาษาไทย สุภาพ ตรงประเด็น เน้นประโยชน์ที่ลูกค้าได้ ("ปิดบัญชีไวขึ้น") มากกว่าชื่อฟีเจอร์
- ห้ามคัดลอกจากเว็บอื่น เขียนใหม่ทั้งหมด · ห้ามอ้างตัวเลข/รางวัล/ลูกค้าที่ไม่จริง — ถ้ายังไม่มีข้อมูลจริง ให้ใส่ข้อมูลสมมติและบอกผู้ใช้ชัดเจนว่าต้องแทนที่
- ปุ่มบอกสิ่งที่จะเกิดจริง ("ขอใบเสนอราคา") ไม่ใช้ "คลิกที่นี่"

## ตรวจก่อนส่ง
1. `npm run build` ต้องผ่าน (รวม type check)
2. เปิด `npm run preview` ดูหน้าที่แก้ ทั้งกว้าง 1280px และมือถือ 390px — ไม่มีข้อความล้น ไม่มี scroll แนวนอน
3. กดลิงก์ที่เพิ่ม/แก้ทุกอันว่าไม่เป็น 404
